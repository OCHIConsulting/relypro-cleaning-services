# RelyPro blog workflow

The blog is generated by Eleventy and edited through Markdown or Pages CMS. Pages
CMS saves Markdown and images to GitHub; Cloudflare Pages then builds and publishes
the approved repository state.

## One-time Pages CMS connection

1. Visit <https://app.pagescms.org/>.
2. Sign in with the GitHub account that can access this repository.
3. Install the Pages CMS GitHub App for `OCHIConsulting/relypro-cleaning-services`.
4. Open the repository. Pages CMS will read `.pages.yml` and show **Blog posts**.
5. Keep new posts as drafts until they have been fact-checked and previewed.

Pages CMS saves content directly to `src/blog/posts/` and uploads blog imagery to
`assets/images/blog/`.

## Create a post

Every post must include:

- A useful, specific title
- A unique search description between 100 and 160 characters
- A lowercase URL slug separated by hyphens
- A relevant category
- An optimized WebP or AVIF cover image and meaningful alternative text
- A link to the most relevant RelyPro service page
- A quote-panel heading and root-relative quote URL
- A reviewed publication date

Set `draft: false` only when the post is approved. Draft posts are excluded from
the website, sitemap and RSS feed.

## AI-assisted workflow

Ask the AI to create a branch and a pull request rather than publishing directly
to `main`. Provide:

1. The primary customer question
2. The relevant RelyPro service
3. The intended Derby audience
4. Verified prices, guarantees and operational facts
5. Any original photographs or first-hand examples

Suggested prompt:

> Draft a RelyPro blog post in `src/blog/posts/` using the existing frontmatter
> schema and house style. Answer the supplied customer question clearly, avoid
> unsupported claims, use UK English, link naturally to the relevant service and
> quote pages, and keep `draft: true`. Run `npm test` and open a pull request for
> human review.

Before approval, check:

- Facts, prices, coverage areas and guarantees against current business policy
- Originality and practical value
- No invented reviews, jobs, statistics or customer stories
- Image rights, image optimization and alternative text
- Title, description, headings and internal links
- Mobile preview and call-to-action wording

## Local commands

```bash
npm install
npm start
```

Eleventy serves the website locally and rebuilds when content or styles change.

```bash
npm test
```

This generates `_site/` and checks existing pages, blog output, structured data,
the sitemap and RSS feed.

## Deployment

Pull requests run the GitHub build-and-test job and receive a Cloudflare branch
preview. After review and production approval, merging to `main` makes the
Git-integrated Cloudflare Pages project build `npm run build` and publish `_site/`.
Pages CMS does not need to move or be replaced.
